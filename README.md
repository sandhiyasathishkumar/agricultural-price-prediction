# Agricultural Commodity Price Prediction

## Project Description

This project develops a machine learning system for predicting agricultural commodity prices using historical market data.

## Dataset

The dataset contains agricultural market information including:

- State
- District
- Market
- Commodity
- Variety
- Grade
- Arrival Date
- Minimum Price
- Maximum Price
- Modal Price

## Machine Learning Models

The project includes:

- Multiple Linear Regression
- Ridge Regression
- Lasso Regression
- Decision Tree Regression
- Hyperparameter Tuning

## Evaluation Metrics

The models are evaluated using:

- MAE
- MSE
- RMSE
- R² Score

## Exploratory Data Analysis

EDA is performed using:

- Histograms
- Bar charts
- Box plots
- Scatter plots
- Correlation heatmap

## RAG-Based Price Query

A RAG-style commodity price search system is included to allow users to search agricultural commodity prices based on market information.

## Dashboard

An interactive Streamlit dashboard presents:

- Dataset summary
- EDA visualizations
- Model performance
- Hyperparameter results
- Commodity price search
- Price query functionality

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit
